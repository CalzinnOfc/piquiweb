# PiquiWeb - Metabuscador Personalizado

PiquiWeb é um metabuscador privado, leve e rápido construído sobre a arquitetura do SearXNG com uma interface customizada.

## Recursos
- Suporte a múltiplos motores de busca (Web, Imagens, Vídeos, Notícias, TI, Ciência e Mapas).
- Autocompletar dinâmico via Google API.
- Interface minimalista e responsiva para mobile e desktop.
- Proxy de imagens e preservação de privacidade.

## Como Executar
```bash
python app.py
```
ou com Docker:
```bash
docker-compose up -d
```
